About Placement Prediction System

Project Introduction

Placement Prediction System uses machine learning techniques to analyze student academic and skill-related information and predict placement outcomes.

Objectives

  • Analyze student academic performance.
  • Analyze technical and soft skills.
  • Predict placement opportunities.
  • Identify important placement factors.
  • Support placement officers in decision making.

Technologies Used

  • Python
  • Flask
  • Pandas
  • NumPy
  • Scikit-learn
  • HTML
  • CSS
  • Machine Learning
